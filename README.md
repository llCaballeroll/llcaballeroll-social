# llCaballeroll Social

Página web personal tipo Linktree para centralizar las redes sociales oficiales de **llCaballeroll**.

## Objetivo

Esta página está pensada para reemplazar servicios externos de enlaces y tener una página propia, limpia, responsiva y alojada en GitHub Pages.

## Redes incluidas

- Facebook
- Instagram
- TikTok
- X
- Threads

## Tecnologías usadas

- HTML5
- CSS3
- Diseño responsivo
- Modo oscuro
- Estilo visual moderno tipo Apple
- Logos externos mediante Simple Icons CDN
